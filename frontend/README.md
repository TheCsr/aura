# AURA Frontend

The React/Vite dashboard frontend is part of the AURA project. For installation, environment configuration, dashboard startup, sensor publishing, and the resident-device demo, see the [project README](../README.md).

Run the frontend development server from this directory with:

```bash
npm run dev
```

The Vite development server proxies `/api` requests to `http://localhost:8000`; start the AURA FastAPI dashboard server separately.
